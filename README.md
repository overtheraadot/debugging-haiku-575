A make.fun entry for **Seventeen Syllables of Debugging**: a small program that
writes one haiku about debugging — three lines in the 5-7-5 syllable shape — to
`entry.txt`. The haiku pictures a red breakpoint holding its breath while the
stack trace points straight at the person who wrote the bug.

## Run

```sh
python3 main.py
```

By default it writes to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
Set `MAKEFUN_OUTPUT_DIR` to choose another directory. It is deterministic,
needs no network and calls no model.

## The haiku

> Red dot holds its breath
> the stack trace points straight at me
> I wrote it, laughing
